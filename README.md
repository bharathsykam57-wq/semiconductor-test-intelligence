# Semiconductor Test Intelligence Platform (STIP)

An AI-powered semiconductor test analytics platform designed to
automate the analysis of silicon test results, detect anomalies,
discover failure patterns, analyse operating conditions and
support engineering investigations.

## Project Objectives

- Automate semiconductor test data processing.
- Analyse voltage, frequency and temperature characterisation.
- Detect anomalous electrical measurements.
- Discover silicon failure signatures using clustering.
- Develop machine learning models for failure classification.
- Investigate correlations across silicon samples and test conditions.
- Generate explainable engineering insights.
- Provide interactive engineering visualisations.

## Dataset

The initial development dataset will contain at least
1,000,000 simulated semiconductor measurement records.

Synthetic data will be clearly distinguished from real
semiconductor measurements.
